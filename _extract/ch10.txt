SQL injection (SQLi) is a major web application vulnerability class prevalent in many web
applications. It is currently ranked third among OWASP's Top 10 Application Security Risks. It is
listed as: A03:2021-Injection

In general, SQLi vulnerabilities enable attackers to meddle with SQL queries exchanged between
the web application and database. SQL vulnerabilities typically allow the attacker to extend the
original application query to include database tables that would normally be inaccessible.

In this Learning Module, we are going to demonstrate both SQL enumeration and database
fingerprinting, along with manual and automated exploitation of SQLi.
